# Development Rules

## General Rules

Write clean code.

Keep functions small.

Keep files modular.

Never duplicate code.

Use reusable components.

---

# File Limits

PHP Files

Maximum 300 lines.

JavaScript Files

Maximum 250 lines.

CSS Files

Maximum 250 lines.

Split files when necessary.

---

# Coding Standards

Use camelCase for variables.

Use PascalCase for classes.

Use meaningful names.

Avoid magic numbers.

Use constants.

Comment only when necessary.

---

# PHP Rules

Use PDO only.

Always use prepared statements.

Never concatenate SQL queries.

Always validate user input.

Always sanitize output.

Use password_hash()

Use password_verify()

Return JSON from APIs.

---

# Frontend Rules

Use semantic HTML.

Responsive first.

Accessible UI.

Reusable CSS classes.

No inline CSS.

No inline JavaScript.

---

# Error Handling

Use try-catch.

Return meaningful API responses.

Never expose SQL errors.

Log internal errors.

Show user-friendly messages.

---

# Security

Validate every request.

Escape HTML output.

Validate uploaded files.

Protect admin routes.

Use JWT authentication.

---

# What To Use

PHP 8+

Bootstrap 5

Axios

PDO

MySQL

Git

GitHub

---

# Avoid

Large files

Global variables

Duplicate code

Mixed HTML and SQL

Deprecated PHP functions

Unsafe file uploads

Unvalidated forms

SQL Injection

Inline styling

Inline scripts
